## Projects

### [hotel-booking-api](https://github.com/JulianAscenzi/hotel-booking-api)
Production-ready REST API for hotel room management and booking workflows.
- JWT authentication with role-based access control (ADMIN / CLIENT)
- Redis caching with configurable TTL, Flyway migrations, Swagger UI
- Full test suite: Mockito unit tests + Testcontainers integration tests
- Multi-stage Dockerfile, Docker Compose with healthchecks, CI with GitHub Actions

`Java 21` `Spring Boot 3` `PostgreSQL` `Redis` `Docker` `JUnit 5`

---

### [movie-recommender](https://github.com/JulianAscenzi/movie-recommender)
Hybrid movie recommendation system built with Python.
- Content-based filtering (TF-IDF over titles and genres) combined with item-item collaborative filtering
- Configurable blend weights between both signals, with automatic fallback to content-only on sparse data
- Usable via CLI or REST API (FastAPI), with interactive Swagger docs
- Full test suite with pytest: unit tests, integration tests, and edge case coverage

`Python` `FastAPI` `scikit-learn` `pandas` `pytest`
